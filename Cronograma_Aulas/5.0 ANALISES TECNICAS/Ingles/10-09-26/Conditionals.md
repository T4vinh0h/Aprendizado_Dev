# Conditionals

## Zero Conditional

### Structure

If + present simple, present simple

### Usage

- General truths
- Scientific facts
- Habits

### Examples

- If you heat water, it boils.
- If I drink coffee, I stay awake.
- If it rains, the ground gets wet.

## First Conditional

### Structure

If + present simple, will + verb

### Usage

- Real possibilities in the future
- Likely situations

### Examples

- If it rains, I will stay home.
- If you study hard, you will pass.
- If she calls, I will answer.

## Second Conditional

### Structure

If + past simple, would + verb

### Usage

- Hypothetical situations
- Imaginary scenarios
- Unlikely present/future

### Examples

- If I had money, I would travel.
- If I were you, I would study more.
- If it snowed here, we would play.

## Third Conditional

### Structure

If + past perfect, would have + past participle

### Usage

- Regrets about the past
- Imaginary past situations
- Things that didn't happen

### Examples

- If I had studied, I would have passed.
- If she had called, I would have answered.
- If we had left earlier, we would have arrived.

## Mixed Conditionals

### Past action, present result

If + past perfect, would + verb

- If I had studied harder, I would be fluent now.

### Present state, past result

If + past simple, would have + past participle

- If I were rich, I would have bought that house.

## Common Mistakes

- Don't use "will" in the if clause
- Use "were" instead of "was" in second conditional
- Pay attention to tense consistency
