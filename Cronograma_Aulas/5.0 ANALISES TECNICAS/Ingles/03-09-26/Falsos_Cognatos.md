# Falsos Cognatos

## O que são Falsos Cognatos?

Os falsos cognatos, também chamados de **false friends**, são palavras que parecem com uma palavra do português, mas possuem significado diferente. O Cambridge define false friend justamente como uma palavra que pode ser confundida com outra de uma língua diferente porque elas se parecem ou soam parecidas, mas possuem significados diferentes.

São as famosas "pegadinhas" do inglês.

## Exemplos Clássicos

### 1. Parents vs Parentes

**Inglês:** My parents are at home.

❌ **Não significa:** "Meus parentes estão em casa."

✅ **Significa:** "Meus pais estão em casa."

### 2. Push vs Puxar

**Inglês:** Push the button.

❌ **Não significa:** "Puxe o botão."

✅ **Significa:** "Empurre o botão."

Este exemplo é particularmente interessante para o trabalho de vocês porque aparece muito no contexto de programação e interfaces. Uma fonte educacional da Secretaria Municipal de Educação de Goiânia também usa push → empurrar como exemplo de falso cognato.

## Exemplos do W3Schools

Palavra em inglês | Significado real | Significado INCORRETO em português
------------------|------------------|-----------------------------------
actual | real / verdadeiro | atual
library | coleção de código (em programação) | biblioteca (como prédio)
parent | elemento "pai" (em HTML) | pai (no sentido familiar)
children | elementos "filhos" (em HTML) | crianças

### Destaque: Actual

Uma boa palavra para destacar é:

**actual → real/verdadeiro**

⚠️ Não confundir com atual em português.

O W3Schools usa a expressão "actual image" em um exemplo de elemento `<figure>`, deixando o termo claramente verificável na fonte.

Também é possível discutir parent e children como vocabulário que pode causar confusão para quem está aprendendo inglês, especialmente porque, em HTML, são utilizados para representar relações hierárquicas entre elementos.

## Resumo

⚠️ **Falso cognato** = parece português, mas significa outra coisa.

**Exemplo:**
- English: parents
- Português: parentes
- 🔴 Parece, mas significa diferente.
