# Cognatos Verdadeiros

## O que são Cognatos?

Cognatos são palavras de línguas diferentes que possuem origem comum e, por isso, geralmente apresentam semelhança na forma e no significado. O Cambridge define cognate justamente como uma palavra que tem a mesma origem ou é relacionada a outra palavra.

Para quem está aprendendo inglês, eles são muito úteis porque você consegue reconhecer o significado com mais facilidade.

## O Segredo dos Cognatos

A palavra é parecida e o significado também é parecido.

- important → importante ✅
- example → exemplo ✅
- different → diferente ✅

## Exemplo Prático

This is an important example.

Tradução: Este é um exemplo importante.

Você provavelmente consegue entender important e example mesmo sem conhecer todas as palavras da frase.

## Resumo

🤝 **Cognato** = parece com o português e possui significado relacionado.

**Exemplo:**
- English: information
- Português: informação
- 🟢 Parece + significa parecido.
