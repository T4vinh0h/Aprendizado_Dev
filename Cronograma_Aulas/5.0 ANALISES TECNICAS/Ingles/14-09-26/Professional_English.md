# Professional English

## Technology English

### Hardware

- Computer - computador
- Laptop - notebook
- Keyboard - teclado
- Mouse - mouse
- Monitor - monitor
- Processor - processador
- Memory - memória
- Hard drive - disco rígido

### Software

- Software - software
- Application - aplicativo
- Program - programa
- Operating system - sistema operacional
- Database - banco de dados
- Interface - interface

### Programming

- Code - código
- Programming - programação
- Developer - desenvolvedor
- Programmer - programador
- Algorithm - algoritmo
- Function - função
- Variable - variável
- Loop - loop/laço
- Array - array/vetor
- String - string/cadeia de caracteres

### Web Development

- Website - site
- Webpage - página web
- Frontend - frontend (parte visual)
- Backend - backend (parte lógica)
- Full stack - full stack
- Framework - framework
- Library - biblioteca
- API - API
- Server - servidor
- Client - cliente

### User Experience

- User Experience (UX) - Experiência do Usuário
- User Interface (UI) - Interface do Usuário
- Design - design
- Layout - layout
- Responsive - responsivo
- Interactive - interativo

## Professional Phrases

### Meetings

- "Let's get started."
- "Can you elaborate on that?"
- "I have a question."
- "I agree with that."
- "I have a different perspective."

### Email

- "I am writing to..."
- "Please find attached..."
- "Let me know if you have questions."
- "I look forward to hearing from you."
- "Best regards"

### Presentations

- "Today I will present..."
- "Let's look at..."
- "As you can see..."
- "In conclusion..."
- "Thank you for your attention."
