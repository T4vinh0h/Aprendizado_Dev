2. Condicionais (if, else, else if)

O QUE SÃO CONDICIONAIS?

Condicionais permitem que o programa tome decisões baseadas em condições. É como o programa "pensar" e escolher entre diferentes caminhos dependendo de situações específicas.

ESTRUTURA BÁSICA

if (condição) {
    // código executado se a condição for verdadeira
} else if (outra_condição) {
    // código executado se a outra condição for verdadeira
} else {
    // código executado se nenhuma condição for verdadeira
}
Importante: apenas um bloco será executado, o primeiro que tiver condição verdadeira.

3. Operadores de Comparação

DEFINIÇÃO

Esses operadores comparam valores e retornam true ou false. São fundamentais para criar condições nas estruturas condicionais.

TABELA COMPLETA DE OPERADORES

OperadorNomeExemploResultado
>Maior que10 > 5true
<Menor que10 < 5false
>=Maior ou igual10 >= 10true
<=Menor ou igual5 <= 10true
==Igual (valor)5 == "5"true
===Igual (valor e tipo)5 === "5"false
!=Diferente (valor)5 != "5"false

DETALHES IMPORTANTES

Prefira sempre === e !== para evitar comportamentos inesperados. O == converte tipos antes de comparar, o que pode causar erros difíceis de achar.

5. Valores Booleanos

DEFINIÇÃO

Booleanos representam apenas dois valores: true (verdadeiro) ou false (falso). São essenciais para controle de fluxo.

EXEMPLO PRÁTICO

// ============================================
// VALORES BOOLEANOS
// ============================================

let ativo = true;
// "ativo" = nome da caixinha
// "="     = "guarde isso aqui dentro"
// "true"  = valor guardado (verdadeiro)

let desativado = false;
// "desativado" = nome da caixinha
// "="           = "guarde isso aqui dentro"
// "false"      = valor guardado (falso)

if (ativo) {
    console.log("O sistema está ativo");
    // mostra "O sistema está ativo" no console
}

Muitas funções e operações retornam valores booleanos, tornando-os essenciais para controle de fluxo.

6. Strings e Manipulação Básica

DEFINIÇÃO

Strings são sequências de caracteres e podem ser manipuladas de várias formas. São imutáveis em JavaScript - métodos retornam novas strings.

EXEMPLO PRÁTICO

// ============================================
// STRINGS E MANIPULAÇÃO BÁSICA
// ============================================

let texto = "JavaScript";
// "texto" = nome da caixinha
// "="     = "guarde isso aqui dentro"
// "JavaScript" = valor guardado (texto)

// Propriedades úteis
console.log(texto.length); // 10 (tamanho)
console.log(texto.toUpperCase()); // "JAVASCRIPT"
console.log(texto.toLowerCase()); // "javascript"
console.log(texto.trim()); // remove espaços

7. Validações de Entrada

DEFINIÇÃO

Validar dados de entrada é essencial para evitar erros e garantir funcionalidade. Sempre valide entrada do usuário antes de processar os dados.

EXEMPLO PRÁTICO

// ============================================
// VALIDAÇÕES DE ENTRADA
// ============================================

// ============================================
// Entrada - recebendo a idade
// ============================================
let idade = Number(prompt("Digite sua idade: "));
// "idade" = nome da caixinha
// "="     = "guarde o resultado aqui dentro"
// Number() = converte para número
// prompt() = pede ao usuário digitar

// ============================================
// Processamento - validando os dados
// ============================================
if (isNaN(idade)) {
    // isNaN verifica se não é um número
    console.log("Por favor, digite um número válido.");
} else if (idade < 0) {
    console.log("Idade não pode ser negativa.");
} else if (idade >= 18) {
    console.log("Você é maior de idade.");
} else {
    console.log("Você é menor de idade.");
}

8. Switch/case

DEFINIÇÃO

O switch/case é uma sintaxe alternativa para múltiplos if/else if quando você precisa comparar a mesma variável com diferentes valores. É mais limpo e organizado em certas situações.

ESTRUTURA BÁSICA

switch (variavel) {
    case valor1:
        // código executado se variavel === valor1
        break;
    case valor2:
        // código executado se variavel === valor2
        break;
    default:
        // código executado se nenhum caso bater
}
Importante: Não esqueça o break em cada case! Sem ele, o código continua executando os próximos casos mesmo depois de encontrar uma correspondência.

9. Operador Ternário (? :)

DEFINIÇÃO

O operador ternário é uma forma compacta de escrever uma decisão simples (if/else) em uma única linha. A sintaxe é: condição ? valorSeVerdadeiro : valorSeFalso.

EXEMPLO PRÁTICO

// ============================================
// OPERADOR TERNÁRIO
// ============================================

let idade = 18;
// "idade" = nome da caixinha
// "="     = "guarde isso aqui dentro"
// "18"    = valor guardado (número)

let resultado = idade >= 18 ? "Maior de idade" : "Menor de idade";
// "resultado" = nome da caixinha
// "="         = "guarde o resultado aqui dentro"
// idade >= 18 = "idade é maior ou igual a 18?"
// ?           = "se for verdadeiro, use isto"
// "Maior de idade" = valor se verdadeiro
// :           = "se for falso, use isto"
// "Menor de idade" = valor se falso

console.log(resultado);
// mostra "Maior de idade" no console
Quando usar: O ternário é ideal para decisões simples. Para lógica complexa, prefira if/else if else para manter o código legível.

10. Comparação Avançada de Números

DEFINIÇÃO

Além de verificar se um número é maior ou menor que outro, podemos comparar de formas mais detalhadas usando diferentes operadores relacionais e lógicos combinados.

Exercício 1 - Comparação Básica

Verifique se o primeiro número é maior que o segundo.

// ============================================
// EXERCÍCIO - COMPARAÇÃO BÁSICA
// ============================================

// ============================================
// Entrada - recebendo os números
// ============================================
let n1 = +prompt(`Digite um Numero`);
// "n1" = nome da caixinha
// "="  = "guarde isso aqui dentro"
// +prompt = converte direto para número

let n2 = +prompt(`Digite outro Numero:`);
// "n2" = nome da caixinha
// "="  = "guarde isso aqui dentro"
// +prompt = converte direto para número

// ============================================
// Processamento - comparando os números
// ============================================
const comparar = (n1 > n2 || n2 > n1);
// "comparar" = nome da caixinha
// "="        = "guarde o resultado aqui dentro"
// n1 > n2    = verifica se o primeiro é maior
// ||         = OU lógico
// n2 > n1    = verifica se o segundo é maior

// ============================================
// Saída - mostrando o resultado
// ============================================
console.log(`Os Numeros ${n1},${n2} tem diferença de: ${comparar}`);

Exercício 2 - Comparação Menor Que

Verifique se o primeiro número é menor que o segundo.

// ============================================
// EXERCÍCIO - COMPARAÇÃO MENOR QUE
// ============================================

let n1 = +prompt(`Digite um Numero`);
let n2 = +prompt(`Digite outro Numero:`);
const comparar = (n1 < n2);
console.log(`${n1} tem diferença de: ${comparar}, comparando ${n2}`);

Exercício 2 - Sistema de Acesso Bancário

Crie um sistema que valide acesso a uma conta bancária com usuário e senha.

// ============================================
// EXERCÍCIO 2 - SISTEMA DE ACESSO BANCÁRIO
// ============================================

// ============================================
// Entrada - dados do sistema
// ============================================
let usuario = "cliente";
// "usuario" = nome da caixinha
// "="       = "guarde isso aqui dentro"
// "cliente" = valor guardado (texto)

const senha = 'banco123';
// "senha" = nome da caixinha (const = não muda)
// "="     = "guarde isso aqui dentro"
// "banco123" = valor guardado (texto)

let saldo = 1168.92;
// "saldo" = nome da caixinha
// "="     = "guarde isso aqui dentro"
// "1168.92" = valor guardado (número decimal)

// ============================================
// Processamento - validando o acesso
// ============================================
if (usuario === 'cliente' && senha === 'banco123') {
    // usuario === 'cliente' = verifica se o usuário está correto
    // &&                   = E lógico (ambos precisam ser verdadeiros)
    // senha === 'banco123' = verifica se a senha está correta
    
    if (saldo > 0) {
        // saldo > 0 = verifica se tem saldo positivo
        console.log(`Acesso Concedido`);
        // mostra "Acesso Concedido" no console
    } else {
        console.log(`Conta sem saldo`);
        // mostra "Conta sem saldo" no console
    }
} else {
    console.log(`Credenciais Incorretas: Usuário ou senha inválidos...`);
    // mostra "Credenciais Incorretas..." no console
}

Exercício 3 - Ano Bissexto

Peça um ano e informe se ele é bissexto usando as regras apropriadas.

// ============================================
// EXERCÍCIO 3 - ANO BISSEXTO
// ============================================

// ============================================
// Entrada - recebendo o ano
// ============================================
let ano = Number(prompt("Digite um ano: "));
// "ano" = nome da caixinha
// "="   = "guarde o resultado aqui dentro"
// Number() = converte para número
// prompt() = pede ao usuário digitar

// ============================================
// Processamento - verificando se é bissexto
// ============================================
let bissexto = false;
// "bissexto" = nome da caixinha
// "="        = "guarde isso aqui dentro"
// "false"    = valor inicial (assume que não é bissexto)

if (ano % 4 === 0) {
    // ano % 4 === 0 = verifica se é divisível por 4
    // % = módulo (resto da divisão)
    
    if (ano % 100 !== 0 || ano % 400 === 0) {
        // ano % 100 !== 0 = não é divisível por 100
        // ||                = OU lógico
        // ano % 400 === 0  = é divisível por 400
        bissexto = true;
        // "bissexto" = atualize o valor da caixinha
        // "="         = "com este novo valor"
        // "true"     = novo valor (é bissexto)
    }
}

// ============================================
// Saída - mostrando o resultado
// ============================================
if (bissexto) {
    console.log(`${ano} é um ano bissexto.`);
} else {
    console.log(`${ano} não é um ano bissexto.`);
}

Exercício 4 - Calculadora de IMC

Peça peso e altura, calcule o IMC e classifique: abaixo do peso, normal, sobrepeso, obesidade grau I, II ou III.

// ============================================
// EXERCÍCIO 4 - CALCULADORA DE IMC
// ============================================

// ============================================
// Entrada - recebendo peso e altura
// ============================================
let peso = +prompt("Digite seu peso (Kg): ");
// "peso" = nome da caixinha
// "="    = "guarde isso aqui dentro"
// +prompt = converte direto para número

let altura = +prompt("Digite sua altura (metros): ");
// "altura" = nome da caixinha
// "="      = "guarde isso aqui dentro"
// +prompt = converte direto para número

// ============================================
// Processamento - calculando o IMC
// ============================================
let imc = peso / (altura * altura);
// "imc" = nome da caixinha
// "="   = "guarde o resultado aqui dentro"
// peso / (altura * altura) = peso dividido por altura ao quadrado

// ============================================
// Processamento - classificando com switch
// ============================================
switch (true) {
    case (imc < 18.5):
        console.log("Classificação: Abaixo do peso");
        break;
    case (imc >= 18.5 && imc < 25.0):
        console.log("Classificação: Peso normal (Saudável)");
        break;
    case (imc >= 25.0 && imc < 30.0):
        console.log("Classificação: Sobrepeso");
        break;
    case (imc >= 30.0 && imc < 35.0):
        console.log("Classificação: Obesidade Grau I");
        break;
    case (imc >= 35.0 && imc < 40.0):
        console.log("Classificação: Obesidade Grau II");
        break;
    case (imc >= 40.0):
        console.log("Classificação: Obesidade Grau III (Mórbida)");
        break;
    default:
        console.log("Não foi possível classificar seu IMC.");
        break;
}

11. Guia rápido de consulta

Esta seção complementa os tópicos anteriores; não substitui os exemplos detalhados.

Preciso...Recurso

Comparar valores>, <, >=, <=, ===, !==

Checklist para resolver um exercício

  1. Identifique quais decisões o programa precisa tomar.
  2. Determine as condições necessárias para cada decisão.
  3. Escolha os operadores de comparação adequados.
  4. Combine condições com operadores lógicos quando necessário.
  5. Valide sempre a entrada de dados antes de processar.
  6. Escreva o fluxo condicional passo a passo.
  7. Teste valores diferentes, incluindo casos-limite.
  8. Se ocorrer um erro, leia a mensagem e confira primeiro as condições, operadores e tipos de dados.
Observação sobre os exemplos: Os exemplos são modelos para estudo. Em exercícios que pedem entrada de dados, adapte os valores fixos para leituras com prompt-sync quando esse for o objetivo. Em exemplos de condição, lembre-se de declarar e atribuir as variáveis utilizadas antes de executar o if.
