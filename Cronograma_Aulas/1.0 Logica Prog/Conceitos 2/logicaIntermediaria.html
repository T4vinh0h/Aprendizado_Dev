Condicionais (if, else, else if)

Condicionais permitem que o programa tome decisões baseadas em condições.

Estrutura básica

if (condição) {
    // código executado se a condição for verdadeira
} else if (outra_condição) {
    // código executado se a outra condição for verdadeira
} else {
    // código executado se nenhuma condição for verdadeira
}
Importante: apenas um bloco será executado, o primeiro que tiver condição verdadeira.

Operadores de Comparação

Esses operadores comparam valores e retornam true ou false:

OperadorNomeExemploResultado
>Maior que10 > 5true
<Menor que10 < 5false
>=Maior ou igual10 >= 10true
<=Menor ou igual5 <= 10true
==Igual (valor)5 == "5"true
===Igual (valor e tipo)5 === "5"false
!=Diferente (valor)5 != "5"false
!==Diferente (valor e tipo)5 !== "5"true
Prefira sempre === e !== para evitar comportamentos inesperados.

Operadores Lógicos

Combinam múltiplas condições:

OperadorNomeExemploResultado
&&E (AND)true && falsefalse
||Ou (OR)true || falsetrue
!Não (NOT)!truefalse
Regra: && exige todas as condições verdadeiras; || exige pelo menos uma verdadeira.

Valores Booleanos

Booleanos representam apenas dois valores: true (verdadeiro) ou false (falso).

let ativo = true;
let desativado = false;

if (ativo) {
    console.log("O sistema está ativo");
}
Muitas funções e operações retornam valores booleanos, tornando-os essenciais para controle de fluxo.

Strings e Manipulação Básica

Strings são sequências de caracteres e podem ser manipuladas de várias formas:

let texto = "JavaScript";

// Propriedades úteis
console.log(texto.length); // 10 (tamanho)
console.log(texto.toUpperCase()); // "JAVASCRIPT"
console.log(texto.toLowerCase()); // "javascript"
console.log(texto.trim()); // remove espaços
Importante: strings são imutáveis em JavaScript - métodos retornam novas strings.

Validações de Entrada

Validar dados de entrada é essencial para evitar erros e garantir funcionalidade:

let idade = Number(prompt("Digite sua idade: "));

if (isNaN(idade)) {
    console.log("Por favor, digite um número válido.");
} else if (idade < 0) {
    console.log("Idade não pode ser negativa.");
} else if (idade >= 18) {
    console.log("Você é maior de idade.");
} else {
    console.log("Você é menor de idade.");
}
Sempre valide entrada do usuário antes de processar os dados.

Exercício 1 - Comparação de Números

Crie um programa que receba dois números e verifique se o primeiro é maior que o segundo.

let n1 = +prompt(`Digite um Numero`);
let n2 = +prompt(`Digite outro Numero:`);
const comparar = (n1 > n2 || n2 > n1);
console.log(`Os Numeros ${n1},${n2} tem diferença de: ${comparar}`);

Exercício 2 - Sistema de Acesso Bancário

Crie um sistema que valide acesso a uma conta bancária com usuário e senha.

let usuario = "cliente";
const senha = 'banco123';
let saldo = 1168.92;

if (usuario === 'cliente' && senha === 'banco123') {
    if (saldo > 0) {
        console.log(`Acesso Concedido`);
    } else {
        console.log(`Conta sem saldo`);
    }
} else {
    console.log(`Credenciais Incorretas: Usuário ou senha inválidos...`);
}
