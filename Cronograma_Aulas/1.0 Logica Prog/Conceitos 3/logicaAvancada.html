Loops (while, for)

Loops permitem executar código repetidamente enquanto uma condição for verdadeira.

While Loop

let i = 1;
while (i <= 10) {
    console.log(i);
    i++;
}

For Loop

for (let i = 1; i <= 10; i++) {
    console.log(i);
}
Diferença: while é melhor quando não sabemos quantas repetições serão necessárias; for é ideal quando sabemos o número exato.

Switch Case

O switch é uma alternativa elegante a múltiplos if/else quando comparamos o mesmo valor:

let dia = "segunda";

switch (dia) {
    case "segunda":
        console.log("Hoje é segunda-feira");
        break;
    case "terca":
        console.log("Hoje é terça-feira");
        break;
    default:
        console.log("Dia não reconhecido");
}
Não esqueça do break em cada case, senão o código continua executando nos próximos casos.

Arrays e Métodos

Arrays são listas ordenadas de valores que podem ser manipulados com métodos específicos:

// Criando um array
let nomes = ["Ana", "Bruno", "Carlos", "Daniela", "Eduardo"];

// Métodos básicos
console.log(nomes.length); // 5 (tamanho)
console.log(nomes[0]); // "Ana" (primeiro elemento)
console.log(nomes.push("Fernanda")); // adiciona ao final
console.log(nomes.pop()); // remove do final
console.log(nomes.shift()); // remove do início
console.log(nomes.unshift("Zoe")); // adiciona no início
Importante: arrays em JavaScript são indexados a partir de 0, não de 1.

Funções Declaradas

Funções são blocos de código reutilizáveis que podem ser chamados quando necessário:

// Declarando uma função
function saudar(nome) {
    return `Olá, ${nome}!`;
}

// Chamando a função
console.log(saudar("Maria")); // "Olá, Maria!"
console.log(saudar("João")); // "Olá, João!"
Use funções para evitar repetição de código e tornar seu programa mais organizado.

Estruturas Aninhadas

Estruturas podem ser combinadas para criar lógicas mais complexas:

for (let i = 1; i <= 3; i++) {
    console.log(`Iteração externa: ${i}`);
    
    for (let j = 1; j <= 2; j++) {
        console.log(`  Iteração interna: ${j}`);
    }
}
Cuidado: estruturas muito aninhadas podem dificultar a leitura do código. Mantenha o nível de aninhamento razoável.

Break e Continue

Comandos para controlar o fluxo de loops:

// Break - sai completamente do loop
for (let i = 1; i <= 10; i++) {
    if (i === 5) {
        break; // para no 5
    }
    console.log(i);
}

// Continue - pula a iteração atual
for (let i = 1; i <= 10; i++) {
    if (i === 5) {
        continue; // pula o 5
    }
    console.log(i);
}
Use break quando encontrar o que procura; use continue quando quiser ignorar casos específicos.

Exercício 4 - Sistema de Média com Recuperação

Crie um programa que leia o nome de um aluno e 4 notas, calcule a média e mostre a situação.

var prompt = require('prompt-sync')();

let nome = prompt(`Digite o nome do Aluno(a): `);
let acumulador = 0;

for (let i = 1; i <= 4; i++) {
    let nota = Number(prompt(`Digite a ${i}º nota de ${nome}: `));
    acumulador += nota;
}

let media = acumulador / 4;
let situacao;

switch (true) {
    case (media >= 7):
        situacao = "Aprovado";
        break;
    case (media >= 5):
        situacao = "Recuperação";
        break;
    default:
        situacao = "Reprovado";
}

console.log(`Nome: ${nome}`);
console.log(`Média: ${media.toFixed(2)}`);
console.log(`Situação: ${situacao}`);
