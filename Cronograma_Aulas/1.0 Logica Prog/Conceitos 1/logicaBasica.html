1. Variáveis e Constantes

O QUE É UMA VARIÁVEL?

Variável é como uma "caixinha com etiqueta" que guarda um valor na memória do computador. Você dá um nome (a etiqueta) e coloca um valor dentro da caixinha.

Exemplo visual de uma variável

📦 [idade] → valor dentro: 20

📦 [nome] → valor dentro: "Maria"

📦 [salario] → valor dentro: 1500

COMO CRIAR UMA VARIÁVEL EM JAVASCRIPT

Em JavaScript, temos 3 formas de criar variáveis. Cada uma tem um propósito específico:

const → Valor FIXO (não muda nunca)

Use const quando o valor NUNCA vai mudar. É mais seguro e evita erros.

// const cria uma caixinha de valor FIXO
const pi = 3.14;
// pi = 3.15;  // ❌ ERRO! const não deixa reatribuir valor

// Exemplo do dia a dia
const nomeDoSite = "Meu Portfólio";
// nomeDoSite nunca vai mudar, então usamos const

let → Valor que PODE mudar

Use let quando você sabe que o valor vai ser atualizado em algum momento.

// let cria uma caixinha que PODE mudar de valor
let contador = 1;
contador = contador + 1; // ✅ funciona! let permite atualizar
console.log(contador); // Resultado: 2

// Exemplo do dia a dia
let notaAluno = 7;
notaAluno = 8; // nota pode mudar, então usamos let

var → Forma antiga (EVITE usar)

var é a forma antiga de criar variáveis (antes de 2015). Funciona parecido com let, mas tem comportamentos estranhos. Hoje em dia EVITA-SE usar var.

// var é a forma antiga
var cidade = "Pelotas";
cidade = "Porto Alegre"; // funciona, mas prefira let

// ❌ EVITE usar var em código novo
// ✅ USE const sempre que possível, let quando necessário
RESUMO DAS ETIQUETAS:

  • const → valor fixo, não muda nunca (USE SEMPRE QUE POSSÍVEL)
  • let → valor pode mudar (use quando sabe que vai atualizar)
  • var → forma antiga, evite usar (só existe por compatibilidade)

REGRAS PARA NOMEAR VARIÁVEIS

Nomes de variáveis precisam seguir algumas regras para funcionar:

✅ PERMITIDO❌ NÃO PERMITIDOMOTIVO
let idade;let 123nome;Não pode começar com número
let nomeCompleto;let let;Não pode usar palavras reservadas
let valor_total;let nome-completo;Não pode usar hífen

2. Tipos de Dados

O QUE SÃO TIPOS DE DADOS?

Tipos de dados são como "formatos" diferentes de informação. Assim como você guarda comida em potes diferentes dependendo do tipo, o computador guarda dados de forma diferente dependendo do tipo.

OS TIPOS PRINCIPAIS EM JAVASCRIPT

string → Texto (sempre entre aspas)

String é qualquer texto. Precisa estar sempre entre aspas (simples ' ou duplas ").

const nome = "Maria";      // aspas duplas
const cidade = 'Pelotas';   // aspas simples
const mensagem = `Olá!`;  // crases (template string)

// ❌ ERRADO - texto sem aspas
// const nome = Maria;  // Isso daria erro!

number → Números (inteiros ou decimais)

Números em JavaScript podem ser inteiros ou decimais. Não usam aspas.

const idade = 25;          // número inteiro
const salario = 1500.50;   // número decimal
const negativo = -10;      // número negativo

// ❌ ERRADO - número com aspas vira texto!
// const idade = "25";  // Isso é string, não number!

boolean → Verdadeiro ou Falso

Boolean só tem dois valores possíveis: true (verdadeiro) ou false (falso). Não usa aspas.

const aprovado = true;     // aprovado = verdadeiro
const reprovado = false;   // reprovado = falso

// ❌ ERRADO - boolean com aspas vira texto!
// const aprovado = "true";  // Isso é string, não boolean!

undefined → Sem valor definido

Quando você cria uma variável mas não dá valor a ela, ela fica undefined (indefinida).

let endereco;  // variável criada mas sem valor
console.log(endereco); // Resultado: undefined

null → Valor nulo/vazio

null é quando você propositalmente diz que a variável está vazia. É diferente de undefined.

let telefone = null;  // propositalmente vazio
console.log(telefone); // Resultado: null

COMO DESCOBRIR O TIPO DE UMA VARIÁVEL

Use o comando typeof para descobrir o tipo de qualquer variável:

const nome = "Maria";
const idade = 25;
const aprovado = true;

console.log(typeof nome);      // "string"
console.log(typeof idade);     // "number"
console.log(typeof aprovado);  // "boolean"
IMPORTANTE: O tipo de dado afeta como o computador processa a informação. Texto "10" + Texto "20" = "1020" (gruda os textos), mas Número 10 + Número 20 = 30 (soma de verdade).

3. console.log - Mostrando Informações

O QUE É console.log?

console.log() é como se fosse uma "impressora" que mostra informações na tela do computador. É a principal forma de ver o que seu programa está fazendo.

DUAS FORMAS DE JUNTAR TEXTO COM VARIÁVEL

Forma 1: Concatenação com "+"

A concatenação "gruda" os textos um do outro. Use o sinal + para juntar.

const nome = "Maria";
const idade = 25;

// Juntando texto com variável usando +
console.log("Nome: " + nome + ", Idade: " + idade);
// Resultado: "Nome: Maria, Idade: 25"

// ⚠️ CUIDADO: com números vira string se um lado já for texto!
console.log("2" + "2");   // "22" (textos grudados, NÃO é soma)
console.log(2 + 2);     // 4 (aqui são números de verdade, soma)

Forma 2: Template Literals (crase + ${})

Template literals são a forma mais moderna e fácil de juntar texto com variáveis. Usa crase ` no lugar de aspas, e ${variavel} para "encaixar" o valor.

const nome = "Maria";
const idade = 25;

// Usando template literals (crase + ${})
console.log(`Nome: ${nome}, Idade: ${idade}`);
// Resultado: "Nome: Maria, Idade: 25"

// Comparando as duas formas fazendo a mesma coisa:
const resultado = 5 + 3;
console.log("O resultado é: " + resultado);   // concatenação
console.log(`O resultado é: ${resultado}`);   // template literal (mais limpo)
BOA PRÁTICA: Prefira sempre template literals (crase + ${}). São mais fáceis de ler, menos propensos a erros, e permitem expressões matemáticas dentro.

OUTRAS FORMAS DE USAR console.log

// Mostrar texto simples
console.log("Olá, mundo!");

// Mostrar variável direto
let nome = "Carlos";
console.log(nome);

// Mostrar múltiplas coisas separadas
console.log("Nome:", nome, "Idade:", 30);

// Mostrar o resultado de uma conta
console.log("Soma:", 10 + 5);
PARA EXECUTAR: No terminal, use node nomedomeuarquivo.js. Certifique-se de estar na pasta correta onde está o arquivo!

4. Template Strings Detalhadas

VANTAGENS DAS TEMPLATE STRINGS

Template strings (crases) são superiores à concatenação tradicional em vários aspectos:

  • Mais legíveis: código mais limpo e fácil de entender
  • Múltiplas linhas: pode quebrar texto em várias linhas sem problemas
  • Expressões: pode fazer contas dentro do texto: ${2 + 2}
  • Menos erros: não precisa se preocupar com aspas e concatenação

EXEMPLO COM MÚLTIPLAS LINHAS

// Template string permite múltiplas linhas facilmente
const texto = `
    Este é um texto
    com várias linhas
    usando template strings.
`;
console.log(texto);

EXPRESSÕES DENTRO DE TEMPLATE STRINGS

const a = 5;
const b = 3;

// Pode fazer contas dentro do ${}
console.log(`A soma de ${a} e ${b} é ${a + b}`);
// Resultado: "A soma de 5 e 3 é 8"

// Pode chamar funções dentro do ${}
const nome = "maria";
console.log(`Nome em maiúsculo: ${nome.toUpperCase()}`);
// Resultado: "Nome em maiúsculo: MARIA"
REGRA DE OURO: Sempre que precisar juntar texto com variáveis, use template strings. Seu código vai ficar muito mais profissional!

5. Operadores Aritméticos

O QUE SÃO OPERADORES ARITMÉTICOS?

São os símbolos matemáticos que usamos para fazer contas em JavaScript: soma, subtração, multiplicação, divisão, etc.

TABELA COMPLETA DE OPERADORES

SímboloNomeExemploResultadoQuando usar
+Adição10 + 515Somar valores
-Subtração10 - 55Subtrair valores
*Multiplicação10 * 550Multiplicar valores
/Divisão10 / 52Dividir valores
%Módulo (resto)10 % 31Pegar resto da divisão
**Potenciação2 ** 38Elevado a potência

EXEMPLOS PRÁTICOS CADA UM

const x = 10;
const y = 3;

// ADIÇÃO (+)
const soma = x + y;
console.log(`Soma: ${soma}`);  // 13

// SUBTRAÇÃO (-)
const subtracao = x - y;
console.log(`Subtração: ${subtracao}`);  // 7

// MULTIPLICAÇÃO (*)
const multiplicacao = x * y;
console.log(`Multiplicação: ${multiplicacao}`);  // 30

// DIVISÃO (/)
const divisao = x / y;
console.log(`Divisão: ${divisao}`);  // 3.33...

// MÓDULO (%) - RESTO DA DIVISÃO
const resto = x % y;
console.log(`Resto de ${x} dividido por ${y}: ${resto}`);  // 1
// Explicação: 10 dividido por 3 dá 3 e sobra 1

// POTENCIAÇÃO (**)
const potencia = x ** y;
console.log(`10 elevado a 3: ${potencia}`);  // 1000

PRECEDÊNCIA DE OPERADORES (ORDEM DOS CÁLCULOS)

Assim como na matemática, alguns cálculos são feitos antes de outros:

// Multiplicação vem antes da adição
let resultado = 2 + 3 * 4;
console.log(resultado);  // 14 (3*4=12, depois 2+12=14)

// Para mudar a ordem, use parênteses
let resultado2 = (2 + 3) * 4;
console.log(resultado2);  // 20 (2+3=5, depois 5*4=20)
ATENÇÃO: Divisão por zero em JavaScript retorna Infinity (infinito). Em outras linguagens isso geralmente causa erro, mas JavaScript é mais "flexível" nesse sentido.
O OPERADOR + TAMBÉM CONCATENA TEXTO: Se um dos lados for texto, o + gruda os textos em vez de somar. Sempre verifique se está trabalhando com números ou texto!

6. Operadores Relacionais

O QUE SÃO OPERADORES RELACIONAIS?

São símbolos usados para COMPARAR valores. Sempre retornam true (verdadeiro) ou false (falso).

TABELA COMPLETA DE OPERADORES RELACIONAIS

SímboloNomeExemploResultadoSignificado
>Maior que10 > 5true10 é maior que 5?
<Menor que2 < 8true2 é menor que 8?
>=Maior ou igual18 >= 18true18 é maior ou igual a 18?
<=Menor ou igual10 <= 20true10 é menor ou igual a 20?
==Igualdade de valor"5" == 5trueValor é igual (converte tipo)?
===Igualdade estrita"5" === 5falseValor E tipo são iguais?
!=Diferença de valor5 != 10trueValor é diferente?
!==Diferença estrita"5" !== 5trueValor ou tipo é diferente?

A DIFERENÇA CRUCIAL: == VS ===

Esta é uma das coisas mais importantes em JavaScript:

== (igualdade de valor)
// Compara apenas o VALOR, convertendo tipos se necessário
console.log("5" == 5);   // true
// JavaScript converte "5" para 5 e compara

console.log("0" == false); // true
// JavaScript converte "0" para 0 e 0 para false
=== (igualdade estrita)
// Compara VALOR E TIPO, não converte nada
console.log("5" === 5);  // false
// String "5" não é igual ao número 5

console.log("0" === false); // false
// String "0" não é igual ao boolean false
REGRA DE OURO: SEMPRE use === e !== (igualdade estrita). Evite == e !=. A igualdade estrita é mais segura e evita bugs difíceis de encontrar.

EXEMPLOS PRÁTICOS

const idade = 18;
const nota = 7;

// Verificando se é maior de idade
console.log(idade >= 18);  // true

// Verificando se a nota é suficiente
console.log(nota >= 7);  // true

// Verificando se a nota é diferente de 10
console.log(nota !== 10);  // true

7. Operadores Lógicos

O QUE SÃO OPERADORES LÓGICOS?

Operadores lógicos combinam várias comparações para criar condições mais complexas. Imagine como os conectivos "E", "OU" da língua portuguesa.

OS TRÊS OPERADORES LÓGICOS

&& (E / AND) - Todos precisam ser verdadeiros

O resultado é true APENAS se TODAS as condições forem true. Se uma for false, o resultado todo é false.

Condição 1Condição 2Resultado (&&)Explicação
truetruetrueAmbos verdadeiros → verdadeiro
truefalsefalseUm falso → falso
falsetruefalseUm falso → falso
falsefalsefalseAmbos falsos → falso

|| (OU / OR) - Pelo menos um precisa ser verdadeiro

O resultado é true se PELO MENOS UMA condição for truefalse se TODAS forem false.

Condição 1Condição 2Resultado (||)Explicação
truetruetruePelo menos um verdadeiro → verdadeiro
truefalsetruePelo menos um verdadeiro → verdadeiro
falsetruetruePelo menos um verdadeiro → verdadeiro
falsefalsefalseNenhum verdadeiro → falso

! (NÃO / NOT) - Inverte o valor

O operador ! inverte o valor lógico: se é true vira false, se é false vira true.

Valor originalResultado (!)Explicação
truefalseInverte verdadeiro → falso
falsetrueInverte falso → verdadeiro

EXEMPLOS PRÁTICOS DO DIA A DIA

// Exemplo 1: Pode entrar no cinema?
let temIngresso = true;
let estaChovendo = false;

// Se tem ingresso E não está chovendo → pode entrar
console.log(temIngresso && !estaChovendo);  // true

// Exemplo 2: Pode pagar?
let temDinheiro = false;
let temCartao = true;

// Se tem dinheiro OU tem cartão → pode pagar
console.log(temDinheiro || temCartao);  // true

// Exemplo 3: Não está chovendo?
let estaChovendo = true;
console.log(!estaChovendo);  // false (está chovendo)

EXPRESSÕES LÓGICAS COMPLEXAS

Podemos combinar múltiplos operadores para criar condições mais elaboradas:

// Exemplo: Verificar aprovação escolar
let nota = 8;
let frequencia = 90;

// Precisa: nota >= 7 E frequencia >= 75
console.log(nota >= 7 && frequencia >= 75);  // true (aprovado)

// Exemplo: Verificar se pode ter carteira de motorista
let idade = 16;
let temAutorizacao = true;

// Precisa: idade >= 18 OU tem autorização dos pais
console.log(idade >= 18 || temAutorizacao);  // true (pode dirigir)
DICA IMPORTANTE: Quando combinar diferentes operadores lógicos, use parênteses para controlar a ordem de avaliação. Isso evita confusão e garante o resultado esperado.

8. Estruturas Condicionais (if/else)

O QUE SÃO ESTRUTURAS CONDICIONAIS?

Condicionais permitem que o programa "pense" e tome decisões baseadas em condições. É como se o programa perguntasse: "Se isso for verdade, faça isso. Se não, faça aquilo."

ESTRUTURA BÁSICA DO if/else

if (condição) {
    // código executado se a condição for verdadeira
} else if (outra_condição) {
    // código executado se a outra condição for verdadeira
} else {
    // código executado se nenhuma condição for verdadeira
}

EXEMPLO COMPLETO: VERIFICANDO IDADE

let idade = 20;

if (idade > 18) {
    console.log("Maior de idade");
} else if (idade === 18) {
    console.log("Acabou de completar 18");
} else {
    console.log("Menor de idade");
}

COMO O if/else FUNCIONA (PASSO A PASSO)

  1. O programa verifica a PRIMEIRA condição (idade > 18)
  2. Se for verdadeira → executa o código dentro das chaves {} e PULA o resto
  3. Se for falsa → vai para o próximo else if
  4. Repete o processo até encontrar uma condição verdadeira
  5. Se nenhuma for verdadeira → executa o else
IMPORTANTE: Apenas UM bloco será executado - o primeiro que tiver condição verdadeira. O programa "pula" todos os outros blocos automaticamente.

EXEMPLO COM OPERADORES LÓGICOS

// Verificar aprovação escolar com múltiplas condições
let nota = 8;
let frequencia = 90;

// Precisa: nota >= 7 E frequencia >= 75
if (nota >= 7 && frequencia >= 75) {
    console.log("Aprovado!");
} else {
    console.log("Reprovado ou em recuperação");
}

if/else SEM else if (apenas duas opções)

let idade = 25;

// Se for maior de idade → entra, senão → não entra
if (idade >= 18) {
    console.log("Pode entrar no evento");
} else {
    console.log("Não pode entrar no evento");
}
BOA PRÁTICA: Sempre use chaves {} mesmo quando o bloco tem apenas uma linha. Isso evita erros e torna o código mais legível.

9. Entrada de Dados com prompt-sync

O QUE É ENTRADA DE DADOS?

Entrada de dados é quando o programa pede informações para o usuário. É como o programa "pergunta" algo e espera a resposta.

COMO USAR prompt-sync

PASSO 1: Instalar a biblioteca

Precisamos instalar uma biblioteca externa para conseguir receber dados do usuário no terminal:

Comando no terminal
npm install prompt-sync

PASSO 2: Importar no seu código

No topo do seu arquivo JavaScript, adicione esta linha:

const prompt = require("prompt-sync")();

PASSO 3: Usar para receber dados

const prompt = require("prompt-sync")();

// O programa mostra a mensagem e espera o usuário digitar
let nome = prompt("Digite seu nome: ");
console.log("Olá, " + nome);

COMO O prompt FUNCIONA (PASSO A PASSO)

  1. O programa mostra a mensagem no terminal
  2. O programa PARA e espera o usuário digitar
  3. O usuário digita e pressiona ENTER
  4. O que foi digitado é guardado na variável
  5. O programa continua executando
⚠️ MUITO IMPORTANTE: O prompt() SEMPRE retorna TEXTO (string), mesmo que o usuário digite números! Isso causa erros se você não converter.

EXEMPLO COMPLETO INTERATIVO

const prompt = require("prompt-sync")();

let nome = prompt("Nome: ");
let idade = prompt("Idade: ");
let cidade = prompt("Cidade: ");

console.log(`Nome: ${nome}`);
console.log(`Idade: ${idade}`);
console.log(`Cidade: ${cidade}`);

10. Conversão de Tipos

POR QUE PRECISAMOS CONVERTER TIPOS?

Como o prompt() sempre retorna texto, se o usuário digitar números e você quiser fazer contas, PRECISA converter de texto para número. Se não converter, o resultado será errado.

O PROBLEMA DA NÃO CONVERSÃO

// ❌ PROBLEMA: sem conversão
let n1 = prompt("Digite um número: ");
let n2 = prompt("Digite outro número: ");
console.log(n1 + n2);  // Se digitar 10 e 20 → "1020" (errado!)

// ✅ SOLUÇÃO: com conversão
let n1 = Number(prompt("Digite um número: "));
let n2 = Number(prompt("Digite outro número: "));
console.log(n1 + n2);  // Se digitar 10 e 20 → 30 (correto!)

AS FUNÇÕS DE CONVERSÃO

Number() - Converte para número (inteiros e decimais)

A função Number() converte qualquer texto numérico para número. Mantém decimais.

EntradaSaídaObservação
Number("123")123Converte texto para número
Number("3.14")3.14Mantém decimais
Number(true)1true vira 1
Number(false)0false vira 0
Number("texto")NaNNot a Number (não é número)
Number("")0String vazia vira 0

parseInt() - Converte para número inteiro

parseInt() converte para número inteiro. IGNORA qualquer parte decimal.

console.log(parseInt("123"));    // 123
console.log(parseInt("8.9"));    // 8 (ignora decimal!)
console.log(parseInt("abc"));    // NaN

parseFloat() - Converte para número decimal

parseFloat() converte para número decimal. MANTÉM as casas decimais.

console.log(parseFloat("7.5"));  // 7.5
console.log(parseFloat("3.14159")); // 3.14159

String() - Converte para texto

Converte qualquer valor para texto (string).

EntradaSaída
String(123)"123"
String(true)"true"
String(null)"null"
String([1, 2, 3])"1,2,3"

Boolean() - Converte para verdadeiro/falso

Converte valores para booleano (true/false).

EntradaSaídaRegra
Boolean(1)trueNúmero diferente de 0 → true
Boolean(0)falseNúmero 0 → false
Boolean("")falseString vazia → false
Boolean("texto")trueString com conteúdo → true

EXEMPLO COMPLETO COM CONVERSÃO

const prompt = require("prompt-sync")();

// Recebendo dados e convertendo imediatamente
let nome = prompt("Nome: ");
let idade = parseInt(prompt("Idade: "));      // converte para inteiro
let altura = parseFloat(prompt("Altura: ")); // converte para decimal

console.log(`Nome: ${nome}`);
console.log(`Idade: ${idade}`);
console.log(`Altura: ${altura}`);
REGRA DE OURO: Sempre que receber dados do usuário com prompt(), converta imediatamente para o tipo esperado. Isso evita 90% dos erros de iniciantes!

11. Erros Comuns e Como Evitar

ERRO 1: Esquecer ponto e vírgula

// ❌ ERRADO - faltando ponto e vírgula
// const X = 200
// const Y = 54
// Funciona na maioria dos casos porque JS "adivinha", mas é má prática

// ✅ CERTO - sempre terminar com ponto e vírgula
const X = 200;
const Y = 54;

ERRO 2: Declarar a mesma variável duas vezes

// ❌ ERRADO - variável repetida (causa erro!)
// const X = 200;
// const X = 9;   // SyntaxError: Identifier 'X' has already been declared

// ✅ CERTO - nomes diferentes para cada conjunto
const X1 = 200;
const X2 = 9;

ERRO 3: Usar acento no nome da variável

// ❌ EVITE - funciona, mas não é recomendado
// const Otávio = 10;

// ✅ CERTO - evitar acentos nos nomes
const Otavio = 10;
const Oivato = 20;

ERRO 4: Não converter prompt para número

// ❌ ERRADO - resultado inesperado
let n1 = prompt("Número: ");
let n2 = prompt("Número: ");
console.log(n1 + n2);  // "1020" em vez de 30

// ✅ CERTO - converter para número
let n1 = Number(prompt("Número: "));
let n2 = Number(prompt("Número: "));
console.log(n1 + n2);  // 30 (correto!)

ERRO 5: Usar == em vez de ===

// ❌ PERIGOSO - igualdade de valor pode causar bugs
// if (idade == "18") { ... }
// Se idade for 18 (número) e "18" (texto), retorna true
// Isso pode causar comportamentos inesperados

// ✅ SEGURO - igualdade estrita
if (idade === 18) { // ... }
// Só retorna true se for número 18
DICA FINAL: A maioria dos erros de iniciantes vem de não converter tipos ou usar os operadores de comparação errados. Sempre converta prompt e sempre use ===.

const prompt = require('prompt-sync')();

Exercício 4 - Cálculo de Média

Objetivo: Receba 3 notas e calcule a média.

const prompt = require('prompt-sync')();

let nota1 = Number(prompt("Digite a primeira nota: "));
let nota2 = Number(prompt("Digite a segunda nota: "));
let nota3 = Number(prompt("Digite a terceira nota: "));

let media = (nota1 + nota2 + nota3) / 3;
console.log(`Sua média é: ${media.toFixed(2)}`);

Exercício 5 - Verificação de Número Par/Ímpar

Objetivo: Receba um número e informe se é par ou ímpar.

const prompt = require('prompt-sync')();

let numero = Number(prompt("Digite um número: "));

    console.log(`${numero} é par.`);
} else {
    console.log(`${numero} é ímpar.`);
