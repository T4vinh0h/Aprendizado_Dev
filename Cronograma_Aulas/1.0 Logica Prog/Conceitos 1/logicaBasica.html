2. Introdução à Lógica e Algoritmos

O QUE É LÓGICA?

Lógica é a capacidade de organizar nosso pensamento de forma estruturada. É como aprender a "pensar de forma organizada" para resolver problemas passo a passo.

O QUE É ALGORITMO?

Algoritmo é uma sequência finita (com início, meio e fim) de passos lógicos para resolver um problema ou realizar uma tarefa específica. Todo algoritmo precisa ser:

  • Claro e bem definido
  • Ter um início óbvio
  • Ter passos lógicos na ordem certa
  • Ter um fim definido

EXEMPLO PRÁTICO: ALGORITMO DO BANHO

Este é um exemplo clássico de algoritmo que todo mundo entende:

Algoritmo para tomar banho (9 passos detalhados)
  1. Entrar no banheiro
  2. Ligar o chuveiro
  3. Ajustar a temperatura da água
  4. Molhar o corpo
  5. Passar sabonete
  6. Enxaguar o corpo
  7. Desligar o chuveiro
  8. Secar o corpo com a toalha
  9. Vestir-se
Exercício proposto: Tente escrever o algoritmo da sua rotina para vir para a aula de Técnico em Desenvolvimento de Sistemas. Comece desde quando você acorda até chegar na sala de aula.

LÓGICA DE PROGRAMAÇÃO NO DIA A DIA

Usamos lógica constantemente, muitas vezes sem perceber. O melhor exemplo é decidir se leva guarda-chuva:

  • Se estiver chovendo → Levar guarda-chuva

Este é um exemplo simples de decisão condicional, que é fundamental na programação.

3. Fluxo: Entrada → Processamento → Saída

OS TRÊS COMPONENTES FUNDAMENTAIS

Todo programa funciona basicamente assim: recebe dados (entrada), processa esses dados (processamento) e apresenta o resultado (saída).

EntradaDados recebidos pelo programaNome do usuário, dois números, idade, senha
ProcessamentoManipulação dos dados através de regrasSomar números, verificar idade, comparar valores, calcular média

5. Variáveis e Tipos de Dados

CONCEITO DE VARIÁVEL

Variável é um espaço reservado na memória para armazenar informações. Pense como caixas com rótulos (etiquetas) onde guardamos diferentes tipos de dados.

Representação visual de variáveis

📦 [myInt] → número inteiro

📦 [myReal] → número decimal

📦 [myChar] → caractere

📦 [myString] → texto

DECLARAÇÃO let VS const

let - Variável que pode mudar

Utilizada para criar variáveis cujo valor pode mudar. Oferece maior flexibilidade.

// Exemplo específico da aula
let contador = 1;
contador = contador + 1;
console.log(contador);  // Resultado: 2

const - Constante que não pode mudar

Utilizada para criar constantes cujo valor não pode ser alterado após a atribuição. É mais seguro.

// Exemplo específico da aula
const pi = 3.14159;
// pi = 10;  // ❌ Isso geraria erro!
Boa prática: Usar const por defeito e let apenas quando precisar de alterar o valor. Atenção: const impede a reatribuição, mas não torna automaticamente imutáveis os objetos e arrays armazenados nela.

REGRAS PARA NOMES DE VARIÁVEIS

✅ PERMITIDO❌ NÃO PERMITIDOMOTIVO
let idade;let 123nome;Não pode começar com números
let nomeCompleto;let let;Não pode usar palavras reservadas
let valor_total;let nome-completo;Não pode usar hífen

TIPOS DE DADOS PRIMITIVOS

O JavaScript identifica o tipo automaticamente (tipagem dinâmica). Os tipos primitivos são:

string - Texto

Textos entre aspas simples ou duplas.

let nome = "Carlos";
console.log(nome);

number - Número

Valores numéricos inteiros e decimais.

let idade = 25;
console.log(idade);

boolean - Booleano/Lógico

Valores lógicos true ou false.

let aprovado = true;
console.log(aprovado);

undefined - Indefinido

Valor que uma variável declarada, mas ainda não inicializada, apresenta por padrão. Também pode aparecer quando se acessa uma propriedade inexistente.

let endereco;
console.log(endereco);  // undefined

null - Nulo

Valor usado intencionalmente para representar a ausência de um valor. É diferente de undefined.

let telefone = null;
console.log(telefone);  // null

Object - Objeto

Array - Lista

Lista ordenada de valores.

ENTRADA E SAÍDA

Saída - console.log()

Exibição de mensagens ou variáveis no console.

Entrada - prompt()

Recolha de dados digitados pelo utilizador.

O PROBLEMA DE ENTRADAS DE TEXTO COM NÚMEROS

O prompt() do navegador e a função retornada por prompt-sync recebem a entrada como texto (string). Mesmo quando a pessoa digita números, é necessário converter o texto para um tipo numérico antes de realizar cálculos.

Exemplo do erro comum
// Se o utilizador digitar 10 e 20:
let n1 = prompt("Digite um número: ");
let n2 = prompt("Digite outro número: ");
console.log(n1 + n2);  // "1020" (concatenação de texto, não soma!)

6. Comando de Saída (console.log)

UTILIZADO PARA VISUALIZAR VARIÁVEIS

O console.log() é utilizado para visualizar variáveis no console.

DUAS FORMAS DE JUNTAR TEXTO COM VARIÁVEL

Forma 1: Concatenação com "+"

Gruda os textos um do lado do outro. Cuidado: com números vira string se um dos lados já for texto!

const a = "1";
const b = "2";

console.log(a + " " + b);       // "1 2"
console.log("2" + "2");         // "22"   (textos grudados, NÃO é soma)
console.log(2 + 2);             // 4      (aqui são números de verdade, soma)
console.log("Gau" + "cho");     // "Gaucho"

Forma 2: Template literals (crase ` + ${})

Forma mais moderna e mais fácil de ler. Usa crase ` no lugar de aspas, e ${variavel} pra "encaixar" o valor dentro do texto.

const exemplo = "mundo";
console.log(`Olá ${exemplo}!`);  // "Olá mundo!"

// Comparando as duas formas fazendo a mesma coisa:
const soma1 = 5 + 3;
console.log("O resultado é: " + soma1);   // concatenação
console.log(`O resultado é: ${soma1}`);   // template literal (mais limpo)

12. Entrada de Dados com prompt-sync

OBJETIVOS

Receber dados do utilizador no terminal de forma interativa e converter textos em números.

CONFIGURAÇÃO E INSTALAÇÃO

Instalar a biblioteca via npm

No terminal: npm install prompt-sync

Importar no topo do script

const prompt = require('prompt-sync')();

UTILIZAÇÃO

let a = prompt("digite um número");

EXEMPLO BÁSICO

const prompt = require('prompt-sync')();
let nome = prompt("Digite seu nome: ");
console.log("Olá, " + nome);

FUNÇÕES DE CONVERSÃO

As conversões não validam sozinhas se a entrada faz sentido para o programa. Por exemplo, texto não numérico pode resultar em NaN; em exercícios maiores, verifique a entrada antes de usar o valor nos cálculos.

Number() - Converte para número (incluindo decimais)

  • Number("123") → 123
  • Number("3.14") → 3.14
  • Number(true) → 1 / Number(false) → 0
  • Number("texto") → NaN (Not a Number)
  • Number("") → 0

parseInt() - Converte para número inteiro

Atenção: ignora partes decimais, parseInt("8.9") resulta em 8.

parseFloat() - Converte para número decimal

parseFloat("7.5")

EXEMPLO PRÁTICO COMPLETO DA AULA 5

const prompt = require("prompt-sync")();

let nome = prompt("Nome: ");
let idade = parseInt(prompt("Idade: "));
let altura = parseFloat(prompt("Altura: "));

console.log(nome);
console.log(idade);
console.log(altura);

13. Funções de Conversão de Tipos Detalhadas

CONVERSÃO PARA STRING()

  • String(123) → "123"
  • String(true) → "true"
  • String(null) → "null" / String(undefined) → "undefined"
  • String([1, 2, 3]) → "1,2,3"

CONVERSÃO PARA BOOLEAN()

  • Boolean(1) → true / Boolean(0) → false
  • Boolean("") → false / Boolean("texto") → true

EXEMPLOS PRÁTICOS COMPLETOS

// Conversão de tipos
console.log(typeof String(123));  // "string"
console.log(typeof Number("123"));  // "number"
console.log(typeof Boolean(1));    // "boolean"

14. Erros Comuns de Sintaxe

ERRO 1: Faltando ponto e vírgula

// ⚠️ Sem ponto e vírgula
// const X = 200
// const Y = 54
// JavaScript geralmente insere ponto e vírgula automaticamente,
// mas manter um padrão explícito pode melhorar a consistência do código.

// ✅ Convenção usada neste material — terminar com ponto e vírgula
const X1 = 200;
const Y1 = 54;

ERRO 2: Variável repetida

// ❌ ERRADO — variável repetida (isso trava o código com erro!)
// const X = 200;
// const X = 9;   // SyntaxError: Identifier 'X' has already been declared

// ✅ CERTO — nomes diferentes pra cada conjunto de dados
const X2 = 9;
const Y2 = 10;
const A2 = 2;

ERRO 3: Convenção de nomes de variáveis (acentos)

// ⚠️ Válido em JavaScript, mas geralmente evitado por convenção
// const Otávio = 10;

// ✅ Convenção recomendada — evitar acentos nos nomes
const Otavio = 10;
const Oivato = 20;
console.log(Otavio + Oivato);  // 30 (soma de verdade, pois são números)
console.log(Otavio / Oivato);  // 0.5
console.log(Otavio - Oivato);  // -10
console.log(Oivato - Otavio);  // 10

EXEMPLO COMPLETO CORRIGIDO

const x3 = 9;
const y3 = 10;
const a3 = 2;

const soma3 = x3 + y3 + a3;
console.log(`Resultado da soma: ${soma3}`);

const media3 = (x3 + y3 + a3) / 3;
console.log(`Resultado da média: ${media3}`);

const multiplicacao3 = x3 * y3 * a3;
console.log(`Resultado da multiplicação: ${multiplicacao3}`);

Checklist para resolver um exercício

  1. Identifique quais dados entram no programa.
  2. Determine o que precisa ser calculado ou verificado.
  3. Escolha variáveis e tipos adequados.
  4. Escreva o processamento passo a passo.
  5. Mostre o resultado com console.log().
  6. Teste valores diferentes, incluindo casos-limite.
  7. Se ocorrer um erro, leia a mensagem e confira primeiro nomes de variáveis, aspas/crases, parênteses e conversões.
