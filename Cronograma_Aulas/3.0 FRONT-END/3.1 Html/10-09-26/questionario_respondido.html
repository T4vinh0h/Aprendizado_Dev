01 - Qual é a diferença entre Internet e Web?

A Internet é a infraestrutura de cabos e servidores que conecta os dispositivos pelo mundo. A Web é o sistema de sites e páginas que opera sobre a estrutura da Internet. É como se a internet fosse uma estrada e a Web os carros transitando na mesma.

02 - Qual é a função do navegador?

É o programa (Chrome, Edge, Firefox) que pede os dados de um site ao servidor, interpreta o código (HTML, CSS, JS) e exibe a página pronta na sua tela.

03 - O que acontece quando acessamos uma página hospedada em um servidor?

O processo ocorre em várias etapas:

  1. Requisição: O navegador envia uma requisição HTTP ao servidor onde a página está hospedada
  2. Processamento: O servidor recebe a requisição, localiza o arquivo e o processa (se necessário)
  3. Resposta: O servidor envia o código HTML (e arquivos associados como CSS, JS, imagens) de volta ao navegador
  4. Renderização: O navegador interpreta o HTML, aplica o CSS e executa o JavaScript
  5. Exibição: A página é renderizada e exibida ao usuário na tela

04 - Qual é a função do HTML?

HTML (HyperText Markup Language) é a linguagem de marcação padrão para criar páginas web. Suas principais funções são:

  • Estruturar conteúdo: Define a hierarquia e organização do conteúdo (títulos, parágrafos, listas)
  • Marcar elementos: Usa tags para indicar o tipo de cada elemento (cabeçalhos, links, imagens, tabelas)
  • Definir semântica: Atribui significado ao conteúdo (header, nav, main, footer)
  • Base para outras tecnologias: Serve como base para CSS (estilo) e JavaScript (interatividade)

HTML não é uma linguagem de programação, é uma linguagem de marcação.

05 - Qual é a diferença entre tag, atributo e conteúdo?

Tag: É o elemento HTML que define o tipo de conteúdo. É escrita entre sinais de menor e maior <tag>. Ex: <h1>, <p>, <a>.

Atributo: São informações adicionais que modificam o comport ou aparência da tag. São especificados dentro da tag de abertura no formato nome="valor". Ex: href="https://...", class="titulo", id="menu".

Conteúdo: É o texto ou elementos que ficam entre a tag de abertura e fechamento. É o que será exibido ao usuário. Ex: <p>Este é o conteúdo</p>.

Exemplo completo: <a href="https://site.com">Clique aqui</a>

06 - O que deve ficar dentro do head?

A seção <head> contém metadados e configurações da página que não são exibidos diretamente no corpo da página. Devem ficar:

  • <title> - Título da página (exibido na aba do navegador)
  • <meta> - Metadados como charset, viewport, descrição, autor
  • <link> - Links para arquivos externos como CSS e ícones
  • <style> - Estilos CSS internos
  • <script> - Scripts JavaScript (quando não precisam ser executados imediatamente)
  • <base> - URL base para links relativos

07 - O que deve ficar dentro do body?

A seção <body> contém todo o conteúdo visível da página que será exibido ao usuário. Devem ficar:

  • Textos: parágrafos, títulos, listas
  • Imagens: elementos visuais
  • Links: hiperlinks para outras páginas
  • Formulários: campos de entrada e botões
  • Tabelas: dados tabulares
  • Divs e Spans: containers para organização
  • Elementos semânticos: header, nav, main, section, article, footer
  • Scripts: JavaScript que precisa ser executado após o carregamento

08 - Qual é a diferença entre title e h1?

<title> (dentro do head):

  • Define o título da página que aparece na aba do navegador
  • É usado por motores de busca para identificar a página
  • Não aparece no corpo da página
  • Deve ser único e descritivo

<h1> (dentro do body):

  • É o cabeçalho principal visível na página
  • Aparece como texto grande no conteúdo da página
  • É importante para hierarquia e SEO
  • Deve haver apenas um h1 por página

Exemplo: title="Meu Site" (aba), h1="Bem-vindo ao Meu Site" (conteúdo)

09 - Para que servem os comentários?

Os comentários em HTML servem para:

  • Documentar o código: Explicar o propósito de seções complexas
  • Fazer anotações: Deixar lembretes para você ou outros desenvolvedores
  • Desativar código temporariamente: "Comentar" código para testes sem deletar
  • Melhorar manutenibilidade: Facilitar a compreensão do código no futuro
  • Organizar seções: Marcar início e fim de blocos de código

Sintaxe: <!-- Este é um comentário -->

Os comentários não são renderizados pelo navegador, são invisíveis para o usuário final.

10 - Por que devemos organizar e indentar o código?

Organizar e indentar o código é essencial porque:

  • Legibilidade: Código bem indentado é mais fácil de ler e entender
  • Manutenção: Facilita encontrar e corrigir erros
  • Colaboração: Outros desenvolvedores conseguem entender seu código mais facilmente
  • Profissionalismo: Demonstra cuidado e boas práticas de programação
  • Evita erros: Ajuda a identificar tags não fechadas e estruturas incorretas
  • Produtividade: Acelera o desenvolvimento e debugging

Indentação significa alinhar o código hierarquicamente usando espaços ou tabs, criando uma estrutura visual clara.
