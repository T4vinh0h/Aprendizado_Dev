Aula de HTML: do zero à primeira página

Nesta aula você vai entender o que é HTML, como um documento é estruturado e como criar textos, links, imagens, listas, tabelas e formulários. Cada conceito vem com um exemplo de código e o resultado que ele produz.

O que é HTML

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). Ele não é uma linguagem de programação: não tem variáveis, condições nem laços. Ele serve para marcar o conteúdo, dizendo ao navegador o que cada pedaço é: um título, um parágrafo, um link, uma imagem.

Pense em uma página web como uma casa. O HTML é a estrutura (paredes e cômodos), o CSS é a decoração (cores e layout) e o JavaScript é a parte elétrica (o que se mexe e reage). Sem HTML, não há página.

Para testar: salve qualquer código desta aula em um arquivo com extensão .html e abra no navegador (duplo clique ou, no VS Code, a extensão Live Server).

Estrutura básica de um documento

Todo documento HTML segue o mesmo esqueleto:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minha primeira página</title>
</head>
<body>
  <!-- Tudo o que aparece na tela fica aqui -->
  <h1>Olá, mundo!</h1>
</body>
</html>
PartePara que serve
<!DOCTYPE html>Avisa ao navegador que o documento usa o HTML5.
<html lang="pt-BR">Elemento raiz. O atributo lang informa o idioma (ajuda leitores de tela e buscadores).
<head>Informações sobre a página que não aparecem na tela: codificação, título da aba, CSS, etc.
<meta charset="UTF-8">Garante que acentos e caracteres especiais (ç, ã, é) apareçam corretamente.
<meta name="viewport">Faz a página se ajustar bem em celulares.
<title>Texto exibido na aba do navegador.
<body>Todo o conteúdo visível da página.

Tags, elementos e atributos

Um elemento é formado por uma tag de abertura, um conteúdo e uma tag de fechamento:

<p>Este é um parágrafo.</p>
<!-- abertura: <p>   conteúdo: Este é um parágrafo.   fechamento: </p> -->

Alguns elementos não têm conteúdo e por isso não precisam de fechamento. São os elementos vazios, como <br>, <hr>, <img> e <input>.

Atributos dão informações extras a um elemento. Ficam dentro da tag de abertura, no formato nome="valor":

<a href="https://www.senacrs.com.br" target="_blank">Site do Senac RS</a>

Elementos também podem ficar aninhados (um dentro do outro). A regra é fechar sempre na ordem inversa da abertura:

<p>Texto com <strong>destaque</strong> no meio.</p>
Erro comum: <p><strong>texto</p></strong> está errado. Quem abriu por último fecha primeiro.

Títulos e textos

Existem seis níveis de título, de <h1> (mais importante) até <h6>. Use um único <h1> por página e não pule níveis só para mudar o tamanho da letra: o tamanho é função do CSS.

<h1>Título principal</h1>
<h2>Seção</h2>
<h3>Subseção</h3>
<p>Um parágrafo com <strong>importância</strong> e <em>ênfase</em>.</p>

Links e imagens

Links com <a>

O atributo href define o destino. Pode ser um endereço externo, outra página do seu projeto ou um ponto da mesma página (usando #id, como o índice desta aula).

<!-- link externo -->
<a href="https://developer.mozilla.org/pt-BR/" target="_blank" rel="noopener">MDN</a>

<!-- link para outra página do projeto -->
<a href="contato.html">Fale conosco</a>

<!-- link para um trecho da mesma página -->
<a href="#formularios">Ir para formulários</a>

Imagens com <img>

<img src="imagens/foto.jpg" alt="Descrição da foto" width="300">
  • src: caminho do arquivo da imagem.
  • alt: texto alternativo. Aparece se a imagem falhar e é lido por leitores de tela. É obrigatório em boas práticas de acessibilidade.
  • width e height: dimensões em pixels.
Caminhos relativos: imagens/foto.jpg procura a pasta imagens ao lado do seu HTML. ../foto.jpg sobe uma pasta. Em repositórios, prefira sempre caminhos relativos, assim o projeto funciona em qualquer máquina e no GitHub Pages.

Listas

Há três tipos: não ordenada (<ul>), ordenada (<ol>) e de descrição (<dl>). Os itens das duas primeiras ficam em <li>.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>Criar o arquivo</li>
  <li>Escrever o código</li>
  <li>Abrir no navegador</li>
</ol>
Resultado
  • HTML
  • CSS
  • JavaScript
  1. Criar o arquivo
  2. Escrever o código
  3. Abrir no navegador

Tabelas

Tabelas servem para dados organizados em linhas e colunas, não para montar o layout da página. A estrutura usa <table>, <tr> (linha), <th> (cabeçalho) e <td> (célula).

<table>
  <thead>
    <tr><th>Disciplina</th><th>Nota</th></tr>
  </thead>
  <tbody>
    <tr><td>Banco de Dados</td><td>9,0</td></tr>
    <tr><td>Orientação a Objetos</td><td>8,5</td></tr>
  </tbody>
</table>
Resultado
DisciplinaNota
Banco de Dados9,0
Orientação a Objetos8,5

Formulários

Formulários coletam dados do usuário. O elemento <form> agrupa os campos; cada campo costuma ter um <label> ligado a ele pelo atributo for (que deve ser igual ao id do campo).

<form action="/enviar" method="post">
  <label for="nome">Nome</label>
  <input type="text" id="nome" name="nome" required>

  <label for="email">E-mail</label>
  <input type="email" id="email" name="email">

  <label for="curso">Curso</label>
  <select id="curso" name="curso">
    <option>Desenvolvimento de Sistemas</option>
    <option>Redes</option>
  </select>

  <label for="msg">Mensagem</label>
  <textarea id="msg" name="msg" rows="4"></textarea>

  <button type="submit">Enviar</button>
</form>
Resultado (exemplo funcional, não envia nada)

Tipos de <input> mais usados:

HTML semântico

Tags semânticas descrevem o significado de cada região da página. Isso ajuda a manter o código organizado, melhora a acessibilidade e facilita o trabalho dos buscadores.

<body>
  <header>
    <h1>Meu site</h1>
    <nav> <!-- menu de links --> </nav>
  </header>

  <main>
    <article>
      <h2>Título do artigo</h2>
      <p>Conteúdo...</p>
    </article>
    <aside> <!-- conteúdo lateral --> </aside>
  </main>

  <footer>
    <p>&copy; 2026 Meu site</p>
  </footer>
</body>
TagSignificado
<header>Cabeçalho da página ou de uma seção.
<nav>Bloco de navegação (menus).
<main>Conteúdo principal. Use apenas um por página.
<section>Seção temática do conteúdo, geralmente com um título.
<article>Conteúdo independente (post, notícia).
<aside>Conteúdo complementar.
<footer>Rodapé.

Div e span: os elementos sem significado

Quando nenhuma tag semântica serve, use os genéricos. O <div> é um bloco (ocupa a linha inteira) e o <span> é em linha (acompanha o texto). Eles ganham sentido com os atributos class e id, que o CSS e o JavaScript usam para encontrá-los.

<div class="cartao" id="cartao-1">
  <p>Status: <span class="ok">concluído</span></p>
</div>
  • class pode se repetir em vários elementos.
  • id é único: não pode haver dois iguais na mesma página.

Boas práticas

  • Sempre declare <!DOCTYPE html>, lang e charset.
  • Use indentação consistente (2 espaços por nível aninhado).
  • Escreva tags e atributos em minúsculas e valores entre aspas.
  • Prefira tags semânticas a <div> quando houver uma adequada.
  • Coloque alt em toda imagem e label em todo campo de formulário.
  • Use HTML para estrutura e CSS para aparência: evite estilizar com tags antigas como <font> ou <center>.
  • Dê nomes claros a arquivos e pastas, sem espaços nem acentos (minha-pagina.html).
  • Valide seu código em validator.w3.org.
  • Comente trechos importantes com <!-- comentário -->.

Exercício final

Crie uma página chamada sobre-mim.html que contenha:

  1. A estrutura básica completa, com lang="pt-BR" e um <title>.
  2. <header> com seu nome em <h1> e <nav> com links para as seções da página.
  3. Uma <section> de apresentação com uma foto (<img> com alt) e dois parágrafos.
  4. Uma <section> com lista das tecnologias que você estuda.
  5. Uma <section> com tabela das disciplinas do curso.
  6. Uma <section> com formulário de contato (nome, e-mail, mensagem e botão).
  7. Um <footer> com o ano e seu nome.
Desafio extra: depois de pronta, valide a página no W3C Validator e corrija os avisos. O próximo passo natural é estilizá-la com CSS.
