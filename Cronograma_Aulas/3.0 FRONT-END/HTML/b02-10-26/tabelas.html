Aula 6: Tabelas

Teoria e prática. Nesta aula você vai ver:

  • quando utilizar uma tabela;
  • por que tabelas não devem controlar o layout;
  • elementos table, tr, th e td;
  • título com caption;
  • organização com thead, tbody e tfoot;
  • atributo scope;
  • mesclagem com rowspan e colspan;
  • cuidados de acessibilidade.

Problematização inicial

Imagine três conteúdos:

  1. uma lista de tecnologias;
  2. uma grade de horários;
  3. uma página dividida em cabeçalho, menu e conteúdo.
Em quais situações existe uma relação clara entre linhas e colunas?

Só na grade de horários: cada informação é cruzada por dois eixos (dia e horário). A lista é uma sequência de itens (ul) e a divisão da página é layout (cabeçalho, menu e conteúdo), que pertence às tags semânticas e ao CSS. A tabela serve para dados com relação entre linhas e colunas.

Quando utilizar uma tabela

Exemplos adequados
  • horários de aulas;
  • relação de cursos;
  • comparação entre tecnologias;
  • resultados de avaliações;
  • preços de produtos;
  • cronograma de atividades;
  • competências profissionais;
  • registros de presença.
Exemplos inadequados
  • posicionar o menu ao lado do conteúdo;
  • organizar cartões de projetos;
  • criar colunas na página;
  • posicionar imagem e texto;
  • estruturar cabeçalho e rodapé.
Tabelas não devem controlar o layout. Para posicionar elementos na página, use HTML semântico (header, nav, main, footer) e CSS (Flexbox e Grid).

Estrutura fundamental

Uma tabela simples utiliza quatro elementos principais:

ElementoFunção
<table>Define a tabela inteira.
<tr> (table row)Define uma linha.
<th> (table header)Define uma célula de cabeçalho.
<td> (table data)Define uma célula de dados.

As células ficam sempre dentro de uma linha, e as linhas dentro da tabela. Uma tabela de 3 linhas por 2 colunas tem 3 tr, cada um com 2 células.

Primeiro exemplo

<table>
  <tr>
    <th>Tecnologia</th>
    <th>Finalidade</th>
    <th>Nível</th>
  </tr>

  <tr>
    <td>HTML</td>
    <td>Estrutura das páginas</td>
    <td>Intermediário</td>
  </tr>

  <tr>
    <td>CSS</td>
    <td>Apresentação visual</td>
    <td>Iniciante</td>
  </tr>
</table>
Resultado
TecnologiaFinalidadeNível
HTMLEstrutura das páginasIntermediário
CSSApresentação visualIniciante

Esses elementos organizam semanticamente e facilitam a estilização. Entretanto, sua presença isolada não resolve todas as questões de acessibilidade. Os cabeçalhos e suas relações ainda precisam estar corretamente definidos.

Por padrão, o navegador não desenha bordas. Para vê-las, use CSS: table, th, td { border: 1px solid #000; }. Evite o antigo atributo border="1".

Cabeçalhos com th e scope

O th indica um cabeçalho. O atributo scope informa a quais células esse cabeçalho se refere, o que ajuda leitores de tela a anunciar o contexto de cada dado:

  • scope="col": o cabeçalho vale para a coluna abaixo dele.
  • scope="row": o cabeçalho vale para a linha à direita dele.
<table>
  <tr>
    <th scope="col">Tecnologia</th>
    <th scope="col">Finalidade</th>
    <th scope="col">Nível</th>
  </tr>
  <tr>
    <th scope="row">HTML</th>
    <td>Estrutura semântica</td>
    <td>Intermediário</td>
  </tr>
</table>
Resultado
TecnologiaFinalidadeNível
HTMLEstrutura semânticaIntermediário

Título com caption

O caption é o título da tabela. Ele deve ser o primeiro filho do table e dizer do que se trata:

<table>
  <caption>Tecnologias estudadas no curso</caption>
  <!-- linhas da tabela -->
</table>
Não coloque o título da tabela em um parágrafo separado: o caption fica ligado à tabela, e os leitores de tela o anunciam junto com ela.

Organização com thead, tbody e tfoot

  • thead: cabeçalho da tabela.
  • tbody: corpo, com os dados principais.
  • tfoot: rodapé, com totais ou resumos.
<table>
  <caption>Tecnologias estudadas no curso</caption>
  <thead>
    <tr><th scope="col">Tecnologia</th><th scope="col">Nível</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">HTML</th><td>Intermediário</td></tr>
    <tr><th scope="row">CSS</th><td>Iniciante</td></tr>
  </tbody>
  <tfoot>
    <tr><th scope="row">Total de tecnologias</th><td>2</td></tr>
  </tfoot>
</table>
Resultado
Tecnologias estudadas no curso
TecnologiaNível

Total de tecnologias2

Mesclagem de células

Duas propriedades permitem que uma célula ocupe mais de uma posição:

  • colspan: a célula se estende por várias colunas.
  • rowspan: a célula se estende por várias linhas.
<!-- colspan: ocupa duas colunas -->
<tfoot>
  <tr>
    <th scope="row" colspan="2">
      Total de tecnologias
    </th>
    <td>5</td>
  </tr>
</tfoot>

<!-- rowspan: ocupa duas linhas -->
<tr>
  <th rowspan="2" scope="rowgroup">
    Desenvolvimento web
  </th>
  <td>HTML</td>
  <td>Estrutura</td>
</tr>
<tr>
  <td>CSS</td>
  <td>Apresentação</td>
</tr>
Resultado
Tecnologias por área
ÁreaTecnologiaPapel
Desenvolvimento webHTMLEstrutura
CSSApresentação
Total de tecnologias2
Com colspan="2", a linha passa a ter uma célula a menos. Com rowspan="2", a linha seguinte também deve ter uma célula a menos. Se a conta não fechar, a tabela se desalinha.

Cuidados com acessibilidade

Uma tabela acessível deve possuir
  • finalidade claramente definida;
  • caption informativo;
  • cabeçalhos marcados com th;
  • scope="col" e scope="row" quando necessário;
  • ordem lógica de leitura;
  • células com conteúdo claro;
  • poucas mesclagens;
  • texto que não dependa exclusivamente de cores;
  • estrutura simples sempre que possível.
Evite
  • usar td para cabeçalhos;
  • colocar o título da tabela em um parágrafo separado;
  • criar células vazias apenas para espaçamento;
  • usar tabelas para organizar o layout;
  • criar mesclagens que dificultem a leitura;
  • apresentar informações apenas por cores;
  • colocar todos os elementos em uma única linha de código.

Prática

No seu portfólio, crie uma página horarios.html com a grade semanal de aulas:

  1. Use caption com um título claro (por exemplo, "Grade de aulas da semana").
  2. Monte o thead com os dias da semana, usando th scope="col".
  3. No tbody, use th scope="row" para o horário e td para a disciplina.
  4. Use rowspan em uma aula que ocupe dois horários seguidos.
  5. Adicione um tfoot com o total de aulas na semana, usando colspan.
  6. Aplique bordas e espaçamento só com CSS e confira se a tabela não depende de cor para ser entendida.
