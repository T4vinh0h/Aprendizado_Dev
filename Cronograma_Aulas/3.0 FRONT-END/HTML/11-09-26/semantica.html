O que é semântica?

Semântica está relacionada ao significado dos elementos utilizados no documento. No HTML, devemos escolher os elementos de acordo com a função do conteúdo, e não apenas pela sua aparência.

<h1>Desenvolvimento de Sistemas</h1>

O elemento h1 informa que o texto é o título principal da página.

Compare duas formas de escrever o mesmo conteúdo:

Sem significado
<p>Formação</p>
<p>Curso Técnico em TDS</p>

A estrutura não revela a relação entre os conteúdos.

Com significado
<h2>Formação</h2>
<p>Curso Técnico em TDS.</p>

A hierarquia fica clara para pessoas e sistemas.

Significado primeiro. Aparência depois.

HTML define a função; CSS define a aparência

HTML: significado
<h1>Sobre mim</h1>

Informa: "este é o título principal".

CSS: apresentação
h1 {
  color: blue;
  font-size: 32px;
}

Informa: "o título será azul e terá 32 px".

Não use uma tag apenas porque ela parece visualmente adequada.

Uma boa estrutura beneficia toda a página

  • Leitura do código: a função de cada trecho fica evidente.
  • Acessibilidade: leitores de tela interpretam melhor o conteúdo.
  • Mecanismos de busca: a organização ajuda a compreender a página.
  • Manutenção: alterações futuras se tornam mais simples.

1. Títulos criam hierarquia

Os elementos h1 a h6 formam a hierarquia do conteúdo. Exemplo de um currículo:

<h1>Currículo de Marina</h1>

<h2>Apresentação</h2>

<h2>Conhecimentos</h2>
  <h3>Desenvolvimento web</h3>
  <h3>Banco de dados</h3>

<h2>Formação</h2>
  • Use um título principal claro (h1).
  • Organize seções com h2.
  • Use h3 dentro de uma seção h2.
  • Evite pular níveis sem necessidade.
  • Não escolha o título pelo tamanho da fonte.

Parágrafos organizam ideias, não o espaçamento

Use um assunto por parágrafo, com o elemento p:

<p>Atualmente, estudo HTML e CSS.</p>

<p>Meu objetivo é trabalhar com
desenvolvimento de software.</p>

Vários espaços no código viram um só. O navegador ignora espaços e quebras de linha repetidos:

<p>HTML       organiza       o
conteúdo.</p>
Resultado

HTML organiza o conteúdo.

Para separar ideias, crie outro <p>. Não use espaços, <br> em sequência ou parágrafos vazios para "dar espaçamento": isso é papel do CSS.

strong e em: importância e ênfase

ElementoSignificadoVisual padrão
<strong>Importância, seriedade ou urgência do trecho.Geralmente aparece em negrito.
<em>Ênfase, mudança de entonação ao ler.Geralmente aparece em itálico.
<p><strong>Atenção:</strong> a entrega é <em>hoje</em>.</p>
Resultado

Atenção: a entrega é hoje.

O visual é consequência; a escolha deve considerar o significado. Se você só quer negrito ou itálico sem importância ou ênfase, use CSS. As tags <b> e <i> existem para casos sem esse sentido, mas a regra é pensar primeiro no significado.

2. Listas organizam relações e sequências

Escolha o tipo de lista conforme a relação existente entre os itens.

TipoElementoQuando usar
Não ordenadaul + liItens sem ordem importante.
Ordenadaol + liSequência ou passos em que a ordem importa.
De definiçõesdl + dt + ddTermos e suas descrições.
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>Criar o arquivo</li>
  <li>Escrever o código</li>
</ol>

Listas de definições relacionam termos e descrições

<dl>
  <dt>HTML</dt>
  <dd>Linguagem de marcação que estrutura o conteúdo.</dd>
  <dt>CSS</dt>
  <dd>Linguagem que define a aparência da página.</dd>
</dl>
Resultado
HTML
Linguagem de marcação que estrutura o conteúdo.
CSS
Linguagem que define a aparência da página.

Uma lista pode detalhar itens de outra lista

A lista interna fica dentro do li do item que ela detalha:

<ul>
  <li>
    Desenvolvimento web
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
</ul>
Resultado
  • Desenvolvimento web
    • HTML
    • CSS
O recuo visual revela que HTML e CSS pertencem ao item "Desenvolvimento web".

3. Citações, siglas, códigos e datas

Citações curtas e longas usam elementos diferentes

q: citação curta (dentro do parágrafo)
<p>Como diz o princípio,
<q>pratique para aprender</q>.</p>

O navegador normalmente adiciona aspas.

blockquote: citação em bloco (trecho separado)
<blockquote cite="https://exemplo.com">
  A aprendizagem é um processo contínuo.
</blockquote>

O atributo cite registra a fonte, mas não a exibe.

Resultado

Como diz o princípio, pratique para aprender.

A aprendizagem é um processo contínuo.

O elemento <cite> pode identificar o título de uma obra:

<p>Li o livro <cite>Dom Casmurro</cite> no semestre passado.</p>

Siglas e datas

Use abbr para siglas e abreviações. O atributo title mostra a forma completa ao passar o mouse. Use time para datas e horários, com o atributo datetime em formato legível por máquinas (AAAA-MM-DD).

<p>
  O <abbr title="Serviço Nacional de Aprendizagem Comercial">SENAC</abbr>
  iniciou as aulas em <time datetime="2026-10-07">7 de outubro de 2026</time>.
</p>
Resultado (passe o mouse sobre a sigla)

O SENAC iniciou as aulas em 7 de outubro de 2026.

Trechos de código: code identifica, pre preserva

code: código dentro de uma frase
<p>Use <code>&lt;h1&gt;</code>
para o título principal.</p>
pre + code: bloco formatado
<pre><code>&lt;h1&gt;Olá!&lt;/h1&gt;
&lt;p&gt;Minha página.&lt;/p&gt;</code></pre>
  • &lt; representa < e &gt; representa >.
  • pre mantém espaços, recuos e quebras de linha.
Sem as entidades &lt; e &gt;, o navegador tentaria interpretar o exemplo como uma tag real e não mostraria o texto na tela.
Resultado

Use <h1> para o título principal.

<h1>Olá!</h1>
<p>Minha página.</p>

4. Bloco e linha descrevem o comportamento visual padrão

  • Elementos de bloco começam em uma nova linha e ocupam toda a largura disponível: h1 a h6, p, ul, ol, li, blockquote, pre, div.
  • Elementos em linha acompanham o fluxo do texto e ocupam só o espaço do conteúdo: strong, em, a, q, abbr, time, code, span.
Resultado: azul = bloco, laranja = em linha
Elemento de bloco 1
Elemento de bloco 2

Texto com linha 1 e linha 2 no mesmo parágrafo.

O CSS pode alterar esse comportamento (propriedade display). A escolha da tag continua baseada no significado.

Síntese: antes de escrever uma tag, faça três perguntas

  1. Que função este conteúdo desempenha?
  2. Ele pertence a qual nível da estrutura?
  3. Existe um elemento HTML mais significativo?
Significado antes da aparência.

Prática

Crie um arquivo curriculo.html sobre você, aplicando tudo desta aula:

  1. Um h1 com seu nome e seções com h2 (Apresentação, Conhecimentos, Formação). Em Conhecimentos, use h3 para subáreas.
  2. Pelo menos dois parágrafos, cada um com um único assunto.
  3. Uma palavra com strong e uma com em, justificando o significado de cada uma.
  4. Uma lista não ordenada de tecnologias com uma lista aninhada, e uma lista ordenada com seus passos de estudo.
  5. Uma lista de definições com dois termos da área.
  6. Uma citação curta (q) e uma citação em bloco (blockquote) com cite.
  7. Uma sigla com abbr e uma data com time.
  8. Um exemplo de código mostrado com pre e code, usando as entidades &lt; e &gt;.
