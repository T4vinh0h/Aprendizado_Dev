# Sufixos

## O que são Sufixos?

Sufixos são partículas adicionadas ao final de palavras para modificar seu significado ou mudar sua classe gramatical.

## Sufixos para Formar Substantivos

### Sufixos Comuns

- **-er/-or** - aquele que faz (teacher, actor, doctor)
- **-ist** - profissional ou especialista (artist, scientist, dentist)
- **-ment** - ação ou resultado (development, improvement, movement)
- **-tion/-sion** - ação ou estado (creation, decision, discussion)
- **-ness** - qualidade ou estado (happiness, darkness, kindness)
- **-ity** - qualidade ou estado (ability, possibility, reality)
- **-ship** - condição ou estado (friendship, relationship, leadership)
- **-dom** - condição ou estado (freedom, kingdom, wisdom)

### Exemplos

- Teach → Teacher (ensinar → professor)
- Act → Actor (atuar → ator)
- Develop → Development (desenvolver → desenvolvimento)
- Create → Creation (criar → criação)
- Happy → Happiness (feliz → felicidade)
- Possible → Possibility (possível → possibilidade)
- Friend → Friendship (amigo → amizade)
- Free → Freedom (livre → liberdade)

## Sufixos para Formar Adjetivos

### Sufixos Comuns

- **-ful** - cheio de ou caracterizado por (helpful, beautiful, careful)
- **-less** - sem ou falta de (hopeless, useless, careless)
- **-able/-ible** - capaz de (readable, visible, possible)
- **-al** - relativo a (natural, educational, professional)
- **-ous** - cheio de ou caracterizado por (famous, dangerous, nervous)
- **-ive** - tendência ou qualidade (active, creative, positive)
- **-y** - caracterizado por (sunny, rainy, cloudy)
- **-ic** - relativo a (artistic, heroic, basic)

### Exemplos

- Help → Helpful (ajudar → prestativo)
- Hope → Hopeless (esperança → sem esperança)
- Read → Readable (ler → legível)
- Nature → Natural (natureza → natural)
- Danger → Dangerous (perigo → perigoso)
- Act → Active (atuar → ativo)
- Sun → Sunny (sol → ensolarado)
- Art → Artistic (arte → artístico)

## Sufixos para Formar Verbos

### Sufixos Comuns

- **-ize/-ise** - tornar-se ou causar (organize, realize, visualize)
- **-ify** - tornar ou causar (clarify, simplify, classify)
- **-ate** - causar ou tornar (activate, create, motivate)
- **-en** - tornar (strengthen, widen, deepen)

### Exemplos

- Organization → Organize (organização → organizar)
- Real → Realize (real → realizar)
- Clear → Clarify (claro → esclarecer)
- Simple → Simplify (simples → simplificar)
- Active → Activate (ativo → ativar)
- Strong → Strengthen (forte → fortalecer)
- Wide → Widen (largo → alargar)

## Sufixos para Formar Advérbios

### Sufixo Principal

- **-ly** - adicionado a adjetivos para formar advérbios (quickly, slowly, carefully)

### Exemplos

- Quick → Quickly (rápido → rapidamente)
- Slow → Slowly (lento → lentamente)
- Careful → Carefully (cuidadoso → cuidadosamente)
- Happy → Happily (feliz → felizmente)
- Beautiful → Beautifully (bonito → lindamente)

## Sufixos Negativos

### Sufixos que Indicam Negativa

- **-un** (unhappy, unfair, unusual)
- **-dis** (disagree, disconnect, dishonest)
- **-im** (impossible, impatient, imperfect)
- **-in** (incorrect, informal, incomplete)
- **-il** (illegal, illogical, illiterate)
- **-ir** (irregular, irrelevant, irresponsible)
- **-non** (nonstop, nonfiction, nonprofit)

### Exemplos

- Happy → Unhappy (feliz → infeliz)
- Agree → Disagree (concordar → discordar)
- Possible → Impossible (possível → impossível)
- Correct → Incorrect (correto → incorreto)
- Legal → Illegal (legal → ilegal)
- Regular → Irregular (regular → irregular)

## Sufixos Numéricos

### Sufixos para Números

- **-teen** - números de 13 a 19 (thirteen, fourteen, fifteen)
- **-ty** - dezenas (twenty, thirty, forty)
- **-th** - números ordinais (fourth, fifth, sixth)

### Exemplos

- Three → Thirteen (três → treze)
- Three → Thirty (três → trinta)
- Four → Fourth (quatro → quarto)

## Padrões de Ortografia

### Mudanças ao Adicionar Sufixos

1. **Dobrar consoante final:**
   - Big → Bigger
   - Wet → Wetter
   - Run → Running

2. **Remover 'e' final:**
   - Create → Creation
   - Hope → Hopeful
   - Write → Writer

3. **Mudar 'y' para 'i':**
   - Happy → Happiness
   - Easy → Easier
   - Beauty → Beautiful

4. **Adicionar 'e' antes de sufixos:**
   - Create → Creative
   - Safe → Safety

## Importância dos Sufixos

### Vantagens de Aprender Sufixos

- Expande vocabulário rapidamente
- Ajuda a entender significados de novas palavras
- Permite deduzir significados de palavras desconhecidas
- Melhora compreensão de leitura
- Facilita formação de palavras

### Estratégias de Aprendizado

- Aprenda sufixos em famílias de palavras
- Pratique identificação de sufixos em textos
- Crie suas próprias palavras usando sufixos
- Use dicionários para verificar formações
- Mantenha um caderno de famílias de palavras

## Exemplos Práticos em Tecnologia

### Sufixos em Terminologia Técnica

- **Program** → **Programmer** (programa → programador)
- **Compute** → **Computer** (computar → computador)
- **Develop** → **Developer** (desenvolver → desenvolvedor)
- **Analyze** → **Analysis** (analisar → análise)
- **Connect** → **Connection** (conectar → conexão)
- **Secure** → **Security** (seguro → segurança)
- **Automate** → **Automation** (automatizar → automação)
- **Digital** → **Digitally** (digital → digitalmente)

## Exercícios Práticos

### Identifique o Sufixo

1. Developer → -er
2. Beautiful → -ful
3. Impossible → -im/-ible
4. Quickly → -ly
5. Creation → -tion

### Forme Novas Palavras

1. Teach + er = Teacher
2. Happy + ness = Happiness
3. Real + ize = Realize
4. Help + ful = Helpful
5. Possible + ity = Possibility

## Resumo

🔤 **Sufixos** = partículas adicionadas ao final das palavras para modificar significado ou classe gramatical.

**Principais benefícios:**
- Expansão rápida de vocabulário
- Compreensão de palavras desconhecidas
- Melhoria na leitura e escrita
- Entendimento de formação de palavras

**Pratique regularmente para dominar o uso de sufixos em inglês!**
