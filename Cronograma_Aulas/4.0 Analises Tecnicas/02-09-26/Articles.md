# Articles

## Indefinite Articles

- A (used before consonant sounds)
- An (used before vowel sounds)

## Definite Article

- The

## Examples

- A computer
- An application
- The website
- A developer
- An algorithm
- The database

## Usage Rules

- A/An: used when mentioning something for the first time or when it's not specific
- The: used when referring to something specific or already mentioned
